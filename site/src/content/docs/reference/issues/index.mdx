Each issue has a stable `MIR####` code that appears in CLI, JSON and SARIF
output. Codes are never reused, so they're safe to reference in suppressions,
baselines and CI filters. [Error codes](./codes/) lists them in numeric order.

Every issue page shows an example and how to fix it. Some issues need to be
turned on:

- Unused classes, functions, methods, properties and constants: `--find-dead-code`.
- Unused variables and foreach values: `--find-dead-code` or `<findUnusedVariables>`.
- Info-level issues, mostly redundancies: `--show-info`.
