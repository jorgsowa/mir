## Adopt it today. Fix issues over time.

<ol class="mir-steps">
  <li>
    <p class="mir-step-title">Install</p>
    <p>Add it as a Composer dev dependency. The prebuilt binary for your platform is downloaded and its checksum verified.</p>
    <code>{'composer require --dev miropen/mir-php'}</code>
  </li>
  <li>
    <p class="mir-step-title">Record a baseline</p>
    <p>Save today's issues so only new ones are reported. Existing <code>{'@psalm-*'}</code> and <code>{'@phpstan-*'}</code> annotations are read as they are.</p>
    <code>{'vendor/bin/mir --set-baseline'}</code>
  </li>
  <li>
    <p class="mir-step-title">Gate every pull request</p>
    <p>Report new issues as inline annotations in CI. Exit code <code>1</code> fails the build.</p>
    <code>{'vendor/bin/mir --format github-actions'}</code>
  </li>
</ol>

## Install

<Tabs syncKey="install">
  <TabItem label="Composer" icon="seti:php">
    ```bash
    composer require --dev miropen/mir-php
    vendor/bin/mir src/
    ```
  </TabItem>
  <TabItem label="Cargo" icon="seti:rust">
    ```bash
    cargo install mir-php
    mir src/
    ```
  </TabItem>
  <TabItem label="From source" icon="seti:shell">
    ```bash
    git clone https://github.com/jorgsowa/mir.git
    cd mir && cargo build --release
    ./target/release/mir src/
    ```
  </TabItem>
</Tabs>
